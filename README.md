# Athulkrishna G Nair Portfolio

A Next.js portfolio for Athulkrishna G Nair, built with Tailwind CSS, GSAP animations, Lenis scrolling, and project detail pages.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Scripts

```bash
npm run dev
npm run build
npm run start
```

## Notes

This project uses an MIT-licensed open-source portfolio template as its code base and has been customized with Athulkrishna G Nair's content and links.
